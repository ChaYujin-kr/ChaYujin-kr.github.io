# Yujin's MLOps Notes

https://chayujin-kr.github.io

[Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) 테마로 만든 Jekyll 블로그입니다. `main`에 push하면 GitHub Actions(`.github/workflows/pages-deploy.yml`)가 빌드해서 GitHub Pages로 배포합니다.

## 글 쓰기

`_posts/YYYY-MM-DD-제목.md` 파일을 만들고 머리말을 붙입니다.

```yaml
---
title: "글 제목"
date: 2026-11-08 10:00:00 +0900
categories: [MLOps, 실습 시리즈]
tags: [drift, kfp]
---
```
